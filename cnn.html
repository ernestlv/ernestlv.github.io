CNN Fundamentals: How machines recognize images

A detailed guide to the convolutional neural network (CNN) concepts. How filters are applied, how feature maps are produced, and how a CNN learns different features of an image.
Abstract

How machines turn pixels into models

A convolutional neural network (CNN) starts with an image that translates into a numerical tensor and repeatedly applies filters to learn the patterns in an image. Hence, each filter produces a map of patterns a feature map. Each feature map represent different aspects of the image.

3. What is a filter?

A filter is a small matrix of weights

Example a 3 × 3 filter:

Filter weights ┌────┬────┬────┐ │ w₁ │ w₂ │ w₃ │ ├────┼────┼────┤ │ w₄ │ w₅ │ w₆ │ ├────┼────┼────┤ │ w₇ │ w₈ │ w₉ │ └────┴────┴────┘ 9 trainable weights

At initialization, the weights are random numbers. A filter is not manually programmed to recognize a feature. The numbers are parameters that the CNN learns during training.

Each layer has its own set of filters with its own learnable weights. During backpropagation, a gradient is calculated for each filter weight, and the optimizer updates each weight accordingly. Although each filter has its own parameters, all layers are trained together because their gradients are connected through the network by the chain rule.

Separate parameters, trained together.

During training, the network makes predictions, calculates a loss, backpropagates gradients, and an optimizer adjusts the filter's weights. Over many training iterations, the weights can become useful for detecting patterns such as edges, textures, or more complex combinations.

4. Convoution Part 1: Producing a cell

Image region (Receptive Field) → filter → activation value

Suppose a 3 × 3 filter is applied at this region of an image:

Local Image Region (Receptive Field) ┌────┬────┬────┐ │ 2 │ 4 │ 1 │ ├────┼────┼────┤ │ 5 │ 3 │ 2 │ ├────┼────┼────┤ │ 1 │ 6 │ 3 │ └────┴────┴────┘

And suppose the filter contains these weights:

Filter ┌────┬────┬────┐ │ 0.2│ 0.1│ 0.3│ ├────┼────┼────┤ │ 0.4│ 0.2│ 0.1│ ├────┼────┼────┤ │ 0.1│ 0.3│ 0.2│ └────┴────┴────┘

The first part of the convolution multiplies corresponding values, sums the products (dot product), and normally adds a bias:

z = Σ(input × filter weight) + bias

That produces one value z. If the layer uses ReLU, the value then passes through the activation function:

a = ReLU(z) = max(0, z)
That final value is the activation and becomes one cell in the feature map.

       ▼
pre-activation z
       │
       │ ReLU
       ▼
activation value a
       │
       ▼
ONE CELL in the feature map
5. Convolution part 2: Moving the filter

One filter produces an entire feature map

A filter is moved across each position in the image and the same calculation is repeated on each row and column of the input image.

For example, the filter can starts from the upper left corner of the image then it moves one column to the left, until it reaches the end of the row; then moves one row down and start from the left again. Initially, each column and row in the image represent pixels. However, after the first convolutional layer completes a feature map is produced and each column or row represent a cell. Therefore new filters in each layer are applied to the feature maps produced in the previous layers.

If the filter responds strongly to a particular pattern, the cells where that pattern occurs will tend to have larger activations.

6. Why there can be many feature maps

Multiple filters look for different characteristics in the image

A convolutional layer normally contains multiple filters. Each filter has its own weights and therefore can learn a different patterns. 

INPUT IMAGE
     │
     ├── Filter 1 ──► Feature map 1
     │
     ├── Filter 2 ──► Feature map 2
     │
     ├── Filter 3 ──► Feature map 3
     │
     ├── Filter 4 ──► Feature map 4
     │
     └── Filter 5 ──► Feature map 5
                 ...

For example, early filters may become sensitive to different edge orientations, color transitions, or simple textures. Other filters may respond to combinations of those features. The network learns these filters during training.

If a layer has 64 output filters and each feature map is 32 × 32, the output can be represented as:

32 × 32 × 64 32 × 32 = cells per feature map 64 = number of feature maps / output channels Total activation values = 32 × 32 × 64 = 65,536
One filter normally corresponds to one feature map/channel, with one activation (cell) at each feature map position.
7. What exactly is an activation?

One cell contains one activation value

An activation is the numeric response of a neuron/channel at a particular location. In the CNN picture we've been using, each cell contains one value.

Feature map ┌──────┬──────┬──────┐ │ 0.12 │ 0.00 │ 0.72 │ ├──────┼──────┼──────┤ │ 0.08 │ 1.34 │ 0.41 │ ├──────┼──────┼──────┤ │ 0.00 │ 0.77 │ 0.23 │ └──────┴──────┴──────┘ Each cell contains one activation value.

A larger positive activation often means the filter produced a stronger response at that location. A value of zero can occur, for example, when ReLU receives a negative pre-activation.

Terminology note: people sometimes say "the activations of a layer" to refer to the entire feature map. In that broader usage, "activation" can mean the tensor as a whole. In this guide, an activation means one value at one cell and channel.
8. Feature map dimensions

What does 32 × 32 feature map mean?

A 32 × 32 feature map means a grid of 32 rows and 32 columns:

32 × 32 = 1,024 cells = 1,024 activation values

It is more precise to call these cells or positions rather than pixels. A cell in a feature map does not necessarily correspond to one original image pixel.

Image → pixels. Feature map → cells containing activations.
9. Receptive field

What does one feature-map cell represent in the original image?

In an early convolutional layer, a filter may be applied to a small region of the input. For example, in the first layer a 3 × 3 filter can apply to a 3 × 3 region of pixels, so the receptive field initially represent that region of 3 x 3 pixels.

The important concept is the receptive field is the region of an earlier input that can influence a particular activation.

10. Going deeper

The receptive field grows as we stack layers

This is where it is useful to distinguish a filter from a receptive field. A filter does not "expand". Instead, as convolutional layers are stacked and pooling is applied, an activation deeper in the network can depend on a larger region of the original image. 

ORIGINAL IMAGE
      │
      ▼
Layer 1
small region, receptive fields closer to pixels
      │
      ▼
Layer 2
each cell represents a larger region of original image

      │
      ▼
Layer 3
each cell correspond to a larger region of the original image

Deeper layers
larger-scale patterns and more abstract representations

For example, an early cell might be influenced by a small patch of pixels. A deeper cell may depend on many cells from earlier layers, and those cells each already depend on regions of the original image. The effective receptive field therefore grows.

Note: pooling makes a feature map smaller; it does not make the filter itself larger. What grows is the amount of the original image region that can influence a deeper activation: its effective receptive field.
11. What pooling changes

Pooling changes resolution, not the filter itself

A pooling operation such as 2 × 2 max pooling summarizes local activations and commonly reduces the height and width of a feature map.

Before pooling: 4 × 4 feature map ┌────┬────┬────┬────┐ │ 1 │ 3 │ 2 │ 1 │ ├────┼────┼────┼────┤ │ 5 │ 4 │ 1 │ 0 │ ├────┼────┼────┼────┤ │ 2 │ 6 │ 3 │ 2 │ ├────┼────┼────┼────┤ │ 1 │ 0 │ 2 │ 7 │ └────┴────┴────┴────┘ 2 × 2 max pooling After pooling: 2 × 2 feature map ┌────┬────┐ │ 5 │ 2 │ ├────┼────┤ │ 6 │ 7 │ └────┴────┘

How four activation values become one pooled cell

With a 2 × 2 pooling window and stride 2, the feature map is divided into non-overlapping groups of four cells. Each group of four activation values is summarized into one activation value in the new feature map. 

4 × 4 FEATURE MAP                         2 × 2 POOLED FEATURE MAP

┌─────────┬─────────┐
│  1   3  │  2   1  │
│  5   4  │  1   0  │       2 × 2        ┌─────┬─────┐
├─────────┼─────────┤   max pooling  →   │  5  │  2  │
│  2   6  │  3   2  │                    ├─────┼─────┤
│  1   0  │  2   7  │                    │  6  │  7  │
└─────────┴─────────┘                    └─────┴─────┘

Each 2 × 2 region on the left corresponds to one cell on the right.

Max pooling

In max pooling, the largest activation in each pooling region is selected. Using the four regions above:

Top-left region: max(1, 3, 5, 4) = 5 Top-right region: max(2, 1, 1, 0) = 2 Bottom-left region: max(2, 6, 1, 0) = 6 Bottom-right region: max(3, 2, 2, 7) = 7 Result: ┌────┬────┐ │ 5 │ 2 │ ├────┼────┤ │ 6 │ 7 │ └────┴────┘

A large activation means that the filter responded strongly to its learned feature at that location. Max pooling therefore preserves the strongest detection within each local region while discarding the exact position of that detection inside the region.

Average pooling

Pooling does not have to select the maximum. Average pooling combines the same four cells by calculating their arithmetic mean. For example, the top-left region becomes:

┌────┬────┐ │ 1 │ 3 │ ├────┼────┤ │ 5 │ 4 │ └────┴────┘ (1 + 3 + 5 + 4) / 4 = 3.25 The four activation values become one activation value: 3.25
Max pooling Four local activation values → keep the largest activation.
Average pooling Four local activation values → calculate their average.

Pooling is applied to every feature map

Pooling normally reduces the spatial dimensions of each feature map independently; it does not combine different feature maps together. If a convolutional layer produced 32 feature maps, each with dimensions 4 × 4, applying 2 × 2 pooling with stride 2 produces 32 feature maps of size 2 × 2.

Before pooling: 4 × 4 × 32 ↓ 2 × 2 pooling ↓ After pooling: 2 × 2 × 32 Height and width shrink. The number of feature maps / channels stays the same.
The key idea: one pooled cell summarizes a group of cells from the previous feature map. With 2 × 2 pooling and stride 2, four previous activation values become one new activation value.

The number of cells is therefore reduced. However, each cell after pooling summarizes information from multiple previous cells, which contributes to the growth of the effective receptive field in later layers.

12. Filter behavior across the CNN

Feature maps become increasingly abstract

A useful high-level picture is:

Pixels
→
Edges / colors
→
Textures / shapes
→
Parts
→
Larger patterns

Early filters operate close to raw pixels. Deeper filters operate on feature maps rather than directly on pixels, so they can learn combinations of lower-level features.

Early layer Small receptive fields; simple local patterns such as edges and basic textures.
Middle layer More combinations of lower-level features; larger effective receptive fields.
Deep layer Features can represent increasingly complex structures using information aggregated from broader regions.

14. One final distinction

“The filter expands” vs. “the receptive field expands”

It is tempting to say that a filter "gets bigger" as the CNN gets deeper. For a standard CNN, that is usually not the best description. A convolutional filter might remain 3 × 3 from one layer to another.

Example: Layer 1 filter: 3 × 3 Layer 2 filter: 3 × 3 Layer 3 filter: 3 × 3 The filter size can stay the same. Yet: Layer 1 cell → sees a relatively small image region Layer 2 cell → can depend on a larger original-image region Layer 3 cell → can depend on an even larger original-image region

That larger dependency comes from stacking operations, including convolutions, and pooling. Thus the thing that "grows" is the receptive field of a deeper activation, not the filter's dimensions.

“As we go deeper in a CNN, the receptive field of deeper activations generally grows, allowing them to incorporate information from larger regions of the original image.”
