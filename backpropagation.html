Backpropagation
Backpropagation calculates a gradient for each weight, and the optimizer updates those weights.

1. Start at the loss

We calculate the gradient of the loss with respect to the final activation a₂.

∂L/∂a₂ = ∂[(a₂ - target)²]/∂a₂ = 2(a₂ - target) = 2(2 - 9) = -14
Gradient at a₂: ∂L/∂a₂ = -14

2Backpropagate the gradient through ReLU at z₂ using the chain rule

Since a₂ = ReLU(z₂) and z₂ = 2 > 0, the ReLU derivative is 1.

∂a₂/∂z₂ = ReLU'(z₂) = ReLU'(2) = 1

Apply the chain rule:

∂L/∂z₂ = ∂L/∂a₂ × ∂a₂/∂z₂ = (-14) × 1 = -14
Gradient at z₂: ∂L/∂z₂ = -14

∂z₁/∂w₁ = x = 5

∂L/∂w₁ = ∂L/∂a₂ × ∂a₂/∂z₂ × ∂z₂/∂a₁ × ∂a₁/∂z₁ × ∂z₁/∂w₁ = (-14) × (1) × (0.8) × (1) × (5) = -56
Gradient for w₁: ∂L/∂w₁ = -56
Optimizer

7. Update the weights with gradient descent

Backpropagation gives us the gradients. The optimizer uses those gradients to update the weights. For this example, use a learning rate of:

η = 0.01

Update w₁

w₁(new) = w₁(old) - η × ∂L/∂w₁ = 0.5 - 0.01 × (-56) = 0.5 + 0.56 = 1.06

Update w₂

w₂(new) = w₂(old) - η × ∂L/∂w₂ = 0.8 - 0.01 × (-35) = 0.8 + 0.35 = 1.15
w₁: 0.50 → 1.06
w₂: 0.80 → 1.15
Backpropagation converts the loss into gradients for each parameter, and the optimizer uses those gradients to decide how to change each weight.
Bias parameters

What is bias and where does it come from?

A bias is another trainable parameter in a neural network. It is added after the weighted input and before the activation function. In our original walkthrough we omitted bias to keep the backpropagation example simple.

Without bias: z₁ = x × w₁ With bias: z₁ = x × w₁ + b₁

For example, if x = 5, w₁ = 0.5, and b₁ = 0.1:

z₁ = x × w₁ + b₁ = 5 × 0.5 + 0.1 = 2.6 a₁ = ReLU(2.6) = 2.6

Weights are commonly initialized with a random value. Biases are also initialized before training with a random value. Both weights and biases are then learned during training.

Each layer has independent bias parameters

Bias is not one shared number across the entire neural network. Different layers have their own independent bias parameters.

Layer 1: z₁ = x × w₁ + b₁ Layer 2: z₂ = a₁ × w₂ + b₂ b₁ and b₂ are independent trainable parameters. They do not need to have the same value.

Backpropagation also calculates bias gradients

Backpropagation calculates gradients for all trainable parameters, not only the weights. That includes the biases.

Layer 1 gradients: ∂L/∂w₁ ∂L/∂b₁ Layer 2 gradients: ∂L/∂w₂ ∂L/∂b₂

The optimizer then uses each parameter's gradient to update that parameter independently.

Learning-rate notation: the symbol η is the Greek letter eta and is commonly used to represent the learning rate. The learning rate controls the size of each optimizer update. For example, η = 0.01 means the optimizer applies 1% of the calculated gradient when performing this simple gradient-descent update.
w₁(new) = w₁(old) - η × ∂L/∂w₁ b₁(new) = b₁(old) - η × ∂L/∂b₁ w₂(new) = w₂(old) - η × ∂L/∂w₂ b₂(new) = b₂(old) - η × ∂L/∂b₂
Backpropagation calculates the gradients. The optimizer uses those gradients to update both weights and biases.

Biases in real neural networks and CNNs

Our example uses one scalar weight and one scalar bias per layer only to make the mathematics easy to follow. Real networks contain many parameters.

Dense / fully connected layer
Bias is typically independent per output neuron. For example, a layer with 100 output neurons normally has 100 bias values.
Convolutional layer
Bias is typically independent per output filter/channel. For example, a convolutional layer with 64 filters normally has 64 bias values.

In a convolutional layer, one filter produces one output feature map. The bias associated with that output filter/channel is added at every spatial position in that filter's feature map.

64 convolution filters ↓ 64 output feature maps / channels ↓ typically 64 independent bias values (one bias associated with each output filter/channel)
Key idea: biases are independent trainable parameters. They are not generally shared across different layers. Backpropagation computes a gradient for each trainable bias, and the optimizer updates each bias using its corresponding gradient.

ReLU derivative

8. How do we calculate the derivative of ReLU?

ReLU, or Rectified Linear Unit, is defined as:

ReLU(x) = max(0, x) ReLU(x) = 0, if x < 0 x, if x ≥ 0

To calculate its derivative, look at the slope of the function in each region. The derivative tells us how much the output changes when the input changes slightly.

Case 1: x < 0

For negative values, ReLU always outputs zero:

x ReLU(x) -3 → 0 -2 → 0 -1 → 0 -0.1 → 0

The graph is horizontal in this region. A horizontal line has slope 0, so:

ReLU'(x) = 0 when x < 0

Case 2: x > 0

For positive values, ReLU simply returns x:

ReLU(x) = x

The line y = x has slope 1, so:

ReLU'(x) = 1 when x > 0

Visual behavior of ReLU

The left side is flat with slope 0. The right side follows y = x with slope 1. The corner at zero is where the behavior changes.

What happens at x = 0?

Exactly at zero, ReLU has a sharp corner. The slope from the left is 0, while the slope from the right is 1. Because the two one-sided slopes are different, the ordinary derivative does not exist at x = 0.

left-hand slope = 0 right-hand slope = 1 0 ≠ 1 Therefore: ReLU'(0) does not exist.

In practical neural-network implementations, we need a value to use during backpropagation. By convention, the derivative at zero is commonly defined as:

ReLU'(0) = 0 (conventional choice)
Final practical rule: ReLU'(x) = 0 for x < 0, ReLU'(x) = 1 for x > 0, and ReLU'(0) is not mathematically defined, but is conventionally taken as 0 in this walkthrough.

Why this matters in backpropagation

During backpropagation, the incoming gradient is multiplied by this local derivative:

∂L/∂z = ∂L/∂a × ReLU'(z)

So if z is negative, the ReLU derivative is 0 and the gradient through that ReLU becomes 0. If z is positive, the derivative is 1 and the incoming gradient passes through unchanged.

Loss function

9. Loss Function Equivalence: Subtraction and How It Works During Backpropagation

In this walkthrough the loss is written as L = (a₂ - target)². You could reverse the subtraction and write L = (target - a₂)² without changing the loss.

(a - target) = -(target - a) Therefore: (a - target)² = [-(target - a)]² = (target - a)²

Using our values a₂ = 2 and target = 9:

(a₂ - target)² = (2 - 9)² = (-7)² = 49 (target - a₂)² = (9 - 2)² = (7)² = 49
Both forms produce exactly the same loss: L = 49.

What happens during backpropagation?

The two forms also produce the same gradient with respect to the prediction a. The second form may initially look as though it should have the opposite sign, but the chain rule introduces an additional -1.

Form 1: L = (a - target)²

∂L/∂a = 2(a - target) For a = 2 and target = 9: ∂L/∂a = 2(2 - 9) = -14

Form 2: L = (target - a)²

Let u = target - a. Then the chain rule gives:

∂L/∂a = ∂L/∂u × ∂u/∂a = 2(target - a) × (-1) = -2(target - a) = 2(a - target)

The -1 appears because:

∂(target - a)/∂a = ∂target/∂a - ∂a/∂a = 0 - 1 = -1

Using our values:

∂L/∂a = 2(9 - 2) × (-1) = 14 × (-1) = -14
So both loss expressions give the same loss and the same backpropagation gradient: ∂L/∂a = -14.

Why do we square the error?

The raw difference a - target can be positive or negative. If we used the raw difference itself as the loss, errors on opposite sides of the target could cancel each other when combining examples.

prediction too low: a - target = 2 - 9 = -7 prediction too high: a - target = 16 - 9 = +7

Squaring makes both errors positive:

(-7)² = 49 (+7)² = 49

Squaring also makes larger errors grow much faster than smaller errors. This means the loss penalizes predictions that are far from the target more strongly.

error = 1 → squared error = 1 error = 2 → squared error = 4 error = 3 → squared error = 9 error = 7 → squared error = 49

Another useful property is that squared error is smooth and differentiable, which gives us a simple gradient that tells the optimizer both the direction and magnitude of the correction:

L = (a - target)² ∂L/∂a = 2(a - target)
If a < target
The gradient is negative. Gradient descent subtracts a negative value, encouraging parameter changes that increase the prediction along the relevant local path.
If a > target
The gradient is positive. Gradient descent subtracts a positive value, encouraging parameter changes that decrease the prediction along the relevant local path.
Important: squared error is useful for this teaching example and is common in regression. It is not the only loss function. Different ML tasks may use losses such as cross-entropy, depending on what the model is learning.
